## 兼容性变更

- `trash_paths.sh` 默认预览，必须显式 `--apply --backup` 才会移动。
- SQL / LevelDB 写入同样要求 `--backup`；选择器错误直接拒绝。
- 备份从少数 MD5 文件升级为完整 SHA-256 内容清单，旧 MD5 备份不能作为自动修改授权。
- 去掉 `--expect-clean` 强制绕过状态入口；默认验收针对重置范围，卸载前提使用 `--uninstalled`。
- shell 启动文件不再执行；原包对 npm/系统状态的推测分类不再用于宣称全机干净。实际自动范围和人工范围明确列在覆盖表中。
