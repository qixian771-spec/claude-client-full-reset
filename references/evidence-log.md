# 验收证据报告

每次清理报告使用以下内容，依据实际结果填写，不补造测试或结论。

| 项目 | 内容 |
| --- | --- |
| 范围 | 用户批准的具体路径、浏览器、profile 与保留项 |
| 前提 | 平台、依赖、应用退出、必要权限 |
| 备份 | 目录、manifest 内容校验结果、是否覆盖全部目标 |
| 预览 | 命中条数及批准清单；不列敏感键值 |
| 执行 | 实际命令、退出码、已完成目标、失败目标及未执行目标 |
| 复核 | 验收命令、退出码、仍有命中及逐项判断 |
| 未覆盖 | 按 coverage-matrix 明示，不能描述为已清零 |
| 恢复 | 可用备份位置及禁止覆盖的恢复条件 |

只有命令实际完成且检查范围内无命中，才可写“所列范围验收通过”。执行失败或部分目标完成时应写明部分状态。退出 0 不证明服务端数据被删除、不证明全盘没有可恢复字节、不证明账号处于新设备。

开发测试与用户机器的清理验收是两件事。仓库的测试通过证明受测行为符合契约，不能替代使用者机器上的路径、权限、版本及备份验证。
