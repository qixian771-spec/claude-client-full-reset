# AI 对话模板：带不懂技术的用户走完全程

本文件给执行本 skill 的 AI 用：用户只说自然语言，AI 负责检测、选路、执行和解释。每一节写明**进入条件 → AI 动作 → 预期 → 对用户说的话 → 下一步 / 停止**。规则、退出码和停止条件以 [执行手册](agent-runbook.md) 为准；本文件不放宽任何一条。

命令按 macOS 书写；Windows 把 `python3 scripts/X.py` 换成 `py -3 scripts\X.py`。引号里的话是示例措辞，可以按语境调整，但不能删掉其中的事实和风险。

## 0. 说话原则

| 原则 | 做法 |
| --- | --- |
| AI 是默认执行者 | 检测、扫描、自检、生成交接文件、读日志都由 AI 直接做；不把命令贴给用户让他自己跑 |
| 只在介入点请用户动手 | 见第 8 节；其余时候不打断用户 |
| 不说术语 | 说“Claude 的聊天记录和缓存”，不说 “trace names”；说“废纸篓/回收站”，不说 “trash_paths” |
| 事实来自输出 | 只转述命令的真实输出和退出码；没跑过的就说没跑 |
| 报错照实转述 | 出现 `[ERROR]` 时说明原因；有 `[下一步]` 或“下一步：”时，用大白话转述那一步，然后停下等用户 |
| 不泄露 | 不复述凭证、环境变量值、浏览器 key/value、进程参数 |

## 1. 开场与只读检测

- **进入条件**：用户提到 Claude 装没装、残留、重置、清理、恢复中的任何一种。
- **对用户说**：“我先只读检查一下这台电脑上 Claude 的情况，不会改动或关闭任何东西，大约几秒钟。”
- **AI 动作**：`python3 scripts/check_environment.py --json`，记录退出码。
- **预期**：退出 0 或 1 且能读到 JSON；退出 2 → 第 7 节“检测失败”。
- **下一步**：第 2 节。

## 2. 解读检测结果

按 `status` 选一句开头，再按附加字段补充；只说有依据的内容。

| 情况 | 对用户说 |
| --- | --- |
| `not_detected` | “常见位置没有发现 Claude 的安装或数据。这不代表你从没用过网页版或别的账号。” |
| `installed` | “发现了 Claude 的安装（{Desktop/命令行}）。我只确认了文件在，没有打开它，也不知道账号状态。” |
| `local_data_only` | “没找到安装，但有 Claude 留下的数据或配置，可能是以前卸载后留下的。” |
| `needs_review` | “有几处情况需要先看清楚：{issues 的大白话}。在弄清之前我不会做任何修改。” |
| `unclassified_items` 非空 | “`.claude` 里还有 {N} 个我不认识的项目（{名称}），工具不会动它们。” |
| `auto_memory_projects` > 0 | “有 {N} 个项目存着 Claude 的‘自动记忆’。如果以后要清理聊天记录，这些记忆会一起被移走，到时我会单独问你。” |
| `credential_locations` 有存在项 | “登录信息保存在 {位置}。我只看了它在不在，没有读取内容；默认会保留。” |
| `CLAUDE_CONFIG_DIR` 提示 | “你设置过自定义的配置目录，我默认检查的位置可能不完整，需要先确认。”→ 停止写入路线 |

- **下一步**：用户只想知道情况 → 第 9 节交付后结束；要安装或配置 → 第 2A 节；要检查残留 → 第 3 节；要清理 → 第 3 节后第 4 节；要恢复 → 第 5 节。

## 2A. 首次安装或配置（执行手册路线 A）

- **进入条件**：用户明确要安装或配置，检测已完成。
- **对用户说（先确认产品）**：“你要用的是桌面版 Claude（像普通应用一样打开），还是在终端里用的 Claude Code？不确定的话，大多数人选桌面版。”
- **AI 动作**：按 [环境检测与配置](environment-check.md) 的首次安装清单，只用官方来源。用户授权安装 Claude Code 时，AI 在终端执行官方安装命令；桌面版的下载和安装向导需要在图形界面里操作，属于介入点 ⑥。
- **介入点 ⑥（图形界面安装或登录）**——对用户说：“请打开 {官方下载页}，下载并运行安装程序；装好后打开 Claude 并自己登录。登录必须由你本人完成，我不会接触账号密码。完成后告诉我。”
- **预期**：重新运行 `python3 scripts/check_environment.py --json`，确认出现了对应的安装路径。
- **对用户说（完成）**：“已经看到 {安装位置}。我只确认了文件在；能不能正常登录和使用，要以你打开后的实际情况为准。”
- **停止**：安装命令非 0 退出、来源不是官方、或用户没有授权安装 → 报告当前状态并停止，不换来源、不换版本。

## 3. 检查残留（只读）

- **进入条件**：用户同意检查，或要为清理确定范围。
- **AI 动作 1**：`python3 scripts/preflight.py --browsers-only --json`。
- **预期**：`apps` 项 ✅；否则是介入点 ①。
- **介入点 ①（退出浏览器）**——对用户说：“扫描浏览器记录前，需要你先完全退出这些浏览器：{应用名}。{平台退出方法，取自“下一步”}。退出好了告诉我。”用户不愿意关 → 只做 `--no-browser` 扫描，并明确说“浏览器部分没有检查”。
- **AI 动作 2**：`python3 scripts/scan_readonly.py`（或用户同意的 `--no-browser`），在 macOS 若被隐私保护拒绝 → 介入点 ②。
- **介入点 ②（完全磁盘访问权限，macOS）**——对用户说：“macOS 不允许当前程序读取废纸篓和 Safari 记录。请打开‘系统设置 → 隐私与安全性 → 完全磁盘访问权限’，给‘终端’打开开关。我现在运行在 {宿主} 里，它的权限不够，所以这一步需要在‘终端’里跑：请在‘终端’里进入 {skill 目录}，运行 `python3 scripts/scan_readonly.py`，把全部输出贴给我。”AI 不改用 `--no-browser` 或其他方式绕过；收到输出后按下面的预期判断。
- **预期**：退出 0 无命中，1 有命中，2 失败。
- **对用户说（有命中）**：“找到 {N} 处和 Claude 相关的线索：{按类别概括}。这些只是线索，不代表都该删；比如 {保留项} 是你的设置，默认保留。”
- **下一步**：只要检查 → 第 9 节结束；要清理 → 第 4 节。

## 4. 清理（写入）

- **进入条件**：检测与检查已完成；用户明确说要清理。
- **AI 动作 1**：根据扫描结果整理 1–10 个具体路径的清单，标出影响与保留项。
- **介入点 ③（确认清单）**——对用户说：“我准备移走这些：{逐项：位置 → 是什么 → 移走后会失去什么}。不会动：{保留项}。移走前会先自动备份，东西会进废纸篓/回收站，可以恢复。{有自动记忆时：其中 {N} 个项目的自动记忆也会一起移走，要保留吗？}确认这个清单吗？”只有用户明确同意的路径才能写进下一步。
- **AI 动作 2**：`python3 scripts/handover.py --target {路径1} --target {路径2}`（需要时加 `--dest`），记录生成的“双击运行”和日志位置。
- **介入点 ④（双击交接文件）**——对用户说：“我已经在桌面准备好‘{文件名}’。接下来需要你：1. 保存手上的工作；2. 退出 {要退出的应用，包括我所在的 {宿主}}；3. 双击这个文件；4. 看它列出的预览，确认无误就输入‘是’并回车，不想继续就随便输入别的。它会先备份再移动，任何一步出错都会停下。完成后再打开我，说一声‘好了’。”
- **AI 动作 3**（用户回来后）：读取同名 `.log`。
- **预期与对用户说**：

| 日志结尾 | 对用户说 |
| --- | --- |
| 退出码 0、`[完成]` | “已经按清单处理好了，备份在 {目录}。验收{无命中 / 还剩 {N} 处，都是 {保留项说明}}。需要恢复随时告诉我。” |
| 退出码 3、`[已取消]` | “你选择了不继续，没有备份也没有移动任何文件。” |
| 退出码 2、`[停止]` | “在‘{步骤}’停下了，原因是 {原因}。{之前完成的步骤}；{有备份时：备份在 {目录}，可以恢复}。{下一步的大白话}。” |
| 没有日志 | “还没看到运行记录，可能文件没有被打开。你双击后窗口里显示了什么？”→ 停止 |

- **边界**：SQLite/LevelDB 精删不走交接文件，按执行手册 C4 单独确认与交接。

## 5. 恢复

- **进入条件**：用户要找回已移走的内容，且有备份目录。
- **AI 动作 1**：`python3 scripts/backup.py --list {备份目录}`（只读）。
- **介入点 ⑤（选择恢复内容）**——对用户说：“这份备份里有：{来源清单}。你要恢复哪些？只恢复你选的，不会覆盖现在已有的文件。”
- **AI 动作 2**：交接给独立终端执行 `--restore … --path … --dry-run`，确认后去掉 `--dry-run`（执行手册路线 D）。
- **对用户说（完成）**：“已恢复 {路径}，内容和备份一致。恢复后再扫描会重新看到这些记录，这是正常的。”

## 5B. 监测与上报（遥测）、域名/CDN、分流规则、第三方与 `claude.ai` 进程兜底（傻瓜式一键补齐）

- **进入条件**：用户要求检查或一键补齐遥测关闭、域名/CDN 分流规则、第三方上报阻断或 `claude.ai` 进程兜底。
- **AI 动作 1**：`python3 scripts/telemetry_routing.py`（只读体检，无需退出应用）。
- **对用户说（发现缺口）**：“我检查了你的遥测配置和代理分流规则：你已经有的设置（比如网关或已设好的规则）我完全不会动；目前还缺 {缺失的遥测项数} 项遥测关闭配置和 {缺失的分流规则数} 条分流/进程兜底规则。需要我直接帮你一键补齐缺失的部分，还是在桌面生成一个双击运行文件给你确认后补齐？”
- **AI 动作 2**：用户要直接一键补齐时运行 `python3 scripts/telemetry_routing.py --apply`（或生成双击文件 `python3 scripts/telemetry_routing.py --launcher`）。
- **对用户说（完成）**：“已经把缺失的遥测关闭项补进 `.claude/settings.json`（原文件已备份在同目录，你原有的设置和网关都没有覆盖），并在 `.claude/routing-rules/` 生成了增量补充规则 `claude-routing-supplement.yaml` 和完整规则模板 `claude-routing-full.yaml`。”

## 6. 常见卡点的话术

| 输出 | 对用户说 |
| --- | --- |
| “相关应用仍在运行（…：{应用名}×{n}）” | “还有 {应用名} 在运行，需要完全退出：{下一步里的退出方法}。退出后告诉我。” |
| macOS `[下一步] macOS 隐私保护…` | 介入点 ② 的话 |
| Windows Edge 常驻 | “Edge 关了窗口还在后台运行。请在 Edge 设置‘系统和性能’里关掉‘启动增强’和‘关闭后继续运行后台扩展’，再退出 Edge。” |
| 回收站拒绝 | “这个位置在 {可移动盘/网络盘/设为直接删除的磁盘} 上，放进去会被永久删除，所以工具拒绝了。{下一步}。” |
| `[EMPTY]` | “这个浏览器配置里的那部分数据库是空的，没有可处理的记录。” |
| 路径被拒（危险路径、不在范围、链接） | “这个位置工具不会处理：{原因的大白话}。我们改成扫描结果里的具体项目。” |

## 7. 必须停下来的情况

| 情况 | 对用户说 | 之后 |
| --- | --- | --- |
| 检测退出 2 或输出不是 JSON | “检查本身出错了：{原因}。在弄清之前我不做任何判断。” | 停止，等待用户处理或提供信息 |
| 需要用户动手的介入点 | 对应介入点的话 | 等用户回复 |
| 用户没有明确同意清单 | “我先不动任何东西，等你确认。” | 停止写入 |
| 任何写入命令非 0 退出 | 第 4 节“退出码 2”的话 | 不重跑、不扩大范围 |
| 出现手册未覆盖的情况 | “遇到了我没把握的情况：{事实}。为了安全我先停下。” | 停止并报告 |

## 8. 介入点一览

| 编号 | 用户要做什么 | 为什么必须是用户 |
| --- | --- | --- |
| ① | 退出浏览器/应用 | 工具和 AI 不替用户结束正在使用的软件 |
| ② | 给终端开完全磁盘访问权限（macOS） | 系统隐私设置由用户决定 |
| ③ | 确认要移走的清单（含自动记忆取舍） | 删除范围必须来自用户 |
| ④ | 退出 AI 宿主、双击交接文件、输入“是” | 写入时 AI 宿主必须退出；最终确认必须由本人做 |
| ⑤ | 选择要恢复的内容 | 恢复范围必须来自用户 |
| ⑥ | 图形界面安装、登录账号 | 账号登录必须本人完成；安装向导在图形界面里 |

## 9. 交付总结

用一张表结束，事实来自输出：

| 项目 | 内容 |
| --- | --- |
| 做了什么 | 检测 / 检查 / 清理 / 恢复，对应命令与退出码 |
| 结果 | 命中数、处理的路径、验收结论 |
| 保留了什么 | 设置、技能、凭证、自动记忆等 |
| 没有做的 | 未检查的范围（浏览器、云端、其他用户……）及原因 |
| 备份与恢复 | 备份目录；恢复方法（有备份时） |
