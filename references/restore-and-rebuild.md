# 备份校验、恢复与保留项

备份只通过 `ditto` 复制。每个源目录递归建立文件 SHA-256、目录与符号链接清单，并与副本和复制后的源比较。失败立即停止；不切换复制工具，不生成虚假的通过结果。

```bash
python3 scripts/backup.py --verify /absolute/backup-directory
python3 scripts/backup.py --restore /absolute/backup-directory
```

恢复前退出支持的客户端、浏览器及编辑器。所有原目标必须不存在；恢复器先检查整批目标，再逐个复制并验证。不会合并、覆盖或替用户删除现有目标。中途失败可能已有前序恢复完成，检查这些目标后再决定下一步，不能盲目重跑。

备份内容校验依赖可信的 `manifest.json`，不是签名或抗恶意篡改机制。不要使用来源不明的备份清单。源自备份后发生变化时，清理会拒绝旧备份；确认应用已退出后重新备份，不能篡改清单匹配当前状态。

默认备份包含 `.claude` 的用户技能、设置、插件等；浏览器、应用本体需 `--include`。符号链接可以作为备份内容保存，但不支持作为自动移动目标或通过符号链接父目录写入。

保留资产是否可重建取决于是否有源码、安装包和完整备份，不凭目录名判断。删除设置可能丢失 MCP、网关及个人配置。恢复旧配置和本地标识的效果以应用实际行为为准，不能承诺产生新设备身份或解除服务端限制。

备份通常包含凭证，只保存在可信位置。是否销毁备份应由用户在确认恢复需求后决定，本工具不自动销毁，也不自动清空废纸篓。
